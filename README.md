# Keyword_Tester_Security_SCAN app_d3_529
Keyword testing app, for running a file over a scanner to check for mal.. keywords in a email or .txt file

Install tips:

using Powershell:
dotnet new console

then put the files in the project folder, then run program button.

after running the program.cs
cd .\bin\Debug\net10.0\    <---- will be in the project folder, left top   \bin\


find the file with .exe extension

create a test file   .txt in the current folder
testdemo529.txt

add some generated keywords for testing and save

demo1:
529_proj_d3_keylog_test.exe testnotesd1.txt
